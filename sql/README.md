This folder contains SQL scripts used to reproduce the analytical outputs used in the DiscoverIQ Power BI dashboard.

The project was processed in Kaggle using Python and DuckDB. These SQL scripts represent the analytical logic used to create BI-ready tables such as executive KPIs, funnel metrics, category performance, product ranking segments, user segmentation, and month-over-month comparisons.

These are not production database views. They are portfolio-ready analytical SQL scripts designed to show how the dashboard metrics were calculated.
